# Glosario

No es un diccionario para memorizar. Es un cuaderno de trabajo.

Para cada término escribí tres cosas:

1. **Qué significa**
2. **Qué problema resuelve**
3. **Un ejemplo de la plataforma médica**

La secuencia es deliberada: primero qué es aprender, después cómo aprende un modelo, después LLMs, después aplicaciones, después investigación.

| --- | --- |

| B. Cómo aprende un modelo | [B-como-aprende-un-modelo.md](B-como-aprende-un-modelo.md) |
| C. Cómo funcionan los LLMs | [C-como-funcionan-los-llms.md](C-como-funcionan-los-llms.md) |
| D. Aplicaciones con LLMs | [D-aplicaciones-con-llms.md](D-aplicaciones-con-llms.md) |
| E. Investigar y mejorar | [E-investigacion-y-mejora.md](E-investigacion-y-mejora.md) |

Cuando aparezca un término nuevo en un paper o en una oferta laboral, no lo dejes suelto: enganchalo a uno de estos bloques. Casi nunca es un concepto aislado; es una combinación de fundamentos.
